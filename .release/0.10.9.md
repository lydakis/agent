# Agent 0.10.9

A patch for 0.10.8. No protocol or schema change since 0.10.8 (protocol 105, schema 115). Restart the daemon and Sonny's windows after upgrading.

## Fixed
- Shell and file calls on a linked machine work again. In 0.10.8 every `shell`, `read`, `write`, `edit` and `apply_patch` call that named a `machine` was refused at once with `invalid_arguments`, on every linked machine: the new argument check read the step with the tool's own reader, which has no `machine` field. Sonny now passes the step's schema with `machine` in it, and the daemon checks a step its client gave a schema for by that schema alone, then puts it to its real gate as before (#1412).

## Tests and docs
- A box agent's shell and file calls on a linked laptop are tested through the real gate, end to end (#1412).
- Release stores: 0.10.8's fixture replaces 0.10.6's, and docs/DAEMON_MEASUREMENTS.md has 0.10.8 against 0.10.7 (#1411).
