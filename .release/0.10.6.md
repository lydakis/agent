# Agent 0.10.6

Since 0.10.5: protocol 100 -> 101, schema 113 -> 114. Stores move forward automatically when the daemon starts, and `libexec/store_down.py` takes one back. Restart the daemon and Sonny's windows after upgrading. The first daemon start after the upgrade vacuums the store once, so a large store takes longer to open that one time (#1349).

**Upgrading with a linked machine:** upgrade the Mac you run `sonny link` on first; it upgrades the box as it connects (#1322). Then run `sonny link <box>` once on the Mac (#1321).

## Daemon
- The store keeps everything and takes less space (lossless): instructions and the texts `configure` events carry are stored once and shared, and an agent idle for 7 days has its history packed with zstd level 3, as Codex packs an untouched rollout. Packing runs one batch at a time only while no turn runs, an agent that works again is unpacked in the background, and the file gives freed pages back as it packs. On a synthetic 2.1 GB store, items went from 1,348 MB to 514 MB, all read back byte for byte. `store_down.py` takes a store back to 113 whole (needs Python 3.14's `compression.zstd` or the `zstandard` module when something is packed) (#1349).
- A bot's commands and `web_fetch` reach only the domains it names: the new bot setting `domains` (`--domain PATTERN[=deny]`, with `--network`) follows Codex's patterns, deny wins, and a lone `*` is refused. Commands get no network of their own and go through a proxy in the daemon, which answers a host the list keeps out with `403` and `x-proxy-error`. `agent tool` takes `--domain` too (#1334).
- One tool for done: `close_agent` closes the calling agent when it names itself, and `mark_done` is gone. The turn that asked runs on to its end, and the agent stays closed until a turn of its starts (#1341).

## Sonny
- Switching leads is instant: `/switch`, Projects' enter, `alt+n` and `/new` change lead in the same process with no blank screen, and Projects' first frame shows every project nested and counted (#1355).
- Going to an agent that needs you lands on what it needs: `alt+n`, and `enter` or a click on its row in `/status`, bring its open question or waiting approval into view, keys stay in the composer, and an answer returns you to the newest (#1353).
- When the person's words set an agent's question aside, the agent is told in one line per question, and decides what to do (#1348).
- A link's browser keeps the person's sign-ins past Chrome 158's new profile protection: `[sonny.links.NAME] browser_signins = "copied"` (default) merges cookies into the kept profile, and `"own"` keeps its own sign-ins, with `sonny link browser` to sign in on the linked machine (#1352).
- Agents follow an MCP server's events (the MCP events extension): each server that offers events is a lookout source `mcp.NAME`, a follow names the event and its arguments, and `sonny mcp events NAME` streams or polls them. Webhook-only events are refused with a reason (#1335).
- Done is closed: tasks close themselves once nothing is left to do, leads once the person says the project is done, and closed agents fold under Done in `/status`, the footer and `/sky`. Existing done marks are turned into closes at a window's start (#1341).
- An agent clicked in the side pane opens beside it when there is room, or in its place, and back returns to the one before. Only the agent in view keeps a Sonny running (#1339).
- A reply that draws nothing hangs no `↳` or `└` row on nothing, so a reopened lead no longer shows a column of bare rows (#1338).
- A lead speaks unasked only for what is worth interrupting the person: `lead.md` drops the extra lines and makes its two reply rules one (#1354).
- A lead takes an edited role, AGENTS.md or skill at its next turn end, window or not: the tool host renews its instructions only on a real change, so a memory save never breaks the cache (#1350).
- Boards: a board step with no text (`do`, or `needs`, `labels`, `for` alone) posts on the first call, and its answer lists the posts the agent had missed (#1344). Plain threads on a board invite opinions as commons talk does, and a turn that opens work asks for opinions once per board (#1345).
- The turn rule starts in the words' column, as Codex's does, and a message's time ends at the conversation's edge (#1351).
- `sonny mcp exec SCRIPT` (or `-` for stdin) runs an `exec` script as the person, outside any agent, with every call on one connection to each server, so a lookout source can page an MCP server whose cursors live in one session (#1347).
- A lookout source's command runs in its own folder, `$SONNY_SOURCE_DIR` (#1346).
