# Agent 0.10.8

Since 0.10.7: protocol 102 -> 105 (#1403, #1406, #1407), schema 114 -> 115 (#1403; the migration runs at daemon start, and `release/store_down.py` takes a store back to 114). Restart the daemon and Sonny's windows after upgrading.

## Daemon
- A stopped turn leaves a note for the model: when a turn ends by an interrupt, its history gets Codex's `<turn_aborted>` note after everything the turn holds, so the next turn knows it was cut off. Only interrupts leave one; `history_items` marks it `stop_note: true` (#1403).
- Every call's arguments are checked against its tool's schema before any gate, rule, load hold or sandbox, so no one is asked to approve a call that could never run. `approve_step` takes `parameters`, the step tool's schema, and Sonny passes each MCP tool's `inputSchema` with the steps it asks about (#1406).
- A background exec's waiting steps outlive its turn, as a direct call's and a yielded call's do; a step only the person may allow stays theirs to answer. A step ended by anything other than its gates is answered `deny` with how it ended (`the call was answered first`, `the call was stopped`, `its turn ended`) instead of `no_pending_step`, and Sonny's exec says how and after how long (#1407).
- A slow disk no longer stalls the daemon's loop: a request that must wait for queued admissions parks its session instead of waiting inline, and audit reads and history search go in stretches, each its own read snapshot, so a long read no longer pins the log (#1409).
- The daemon's config-file watch and AWS signer moved, unchanged, into `agent-client`, shared with Sonny (#1391, #1401).

## Sonny
- Typing and scrolling stay smooth on a slow disk: the places note is written beside the window, and `/switch`, side chats, `/audit`, `/usage`, `/context` and a reaction's first reply read the daemon beside the key loop (#1409).
- The lookout watches the follows folder with the kernel (inotify on Linux, kqueue on macOS) instead of reading every file every 15 seconds: any writer's follow is live at once, only changed files are read, and `until` is timed exactly. The 15 s timer remains as a fallback where the folder can't be watched (#1391).
- Each follow's digest counts from its own notes, so news one follow holds is never later than its digest however much follows overlap (#1404).
- A card stays open until the person picks or the agent closes it; words about something else close nothing, and deadlines fire unless the card was picked or closed (#1402).
- A call held for the person reaches the superlead even when the agent that made it has closed (#1408).
- An MCP call under `auto` asks unless its tool says it only reads (or says it is neither destructive nor open-world), as in Codex (#1400).
- MCP servers behind AWS IAM: `sonny mcp add NAME --url URL --sigv4 SERVICE --region REGION` signs every request with SigV4 from the AWS credential chain, MCP events included (#1401).
- A commons reply always posts on the first call and shows the posts its author missed (#1397). A commons read with no `from` opens at the first post the reader was not shown, or for a long thread the opening post plus the newest page (#1405).
- The lookout judges a reply with the window's one "shows nothing" check, so a reply of only zero-width characters reads as an ending, not a reply (#1399).
- A task whose worktree was removed gets it back from its kept branch when its agent runs again; with the branch gone too, its tools run in its state folder and the answer says so (#1398).
- Rex brings Sonny back after a restart (OSC 7577 program resume), as Herdr and cmux already do (#1396).
- Windows opening together no longer lose the first-reads lock to a command started meanwhile (#1410).
